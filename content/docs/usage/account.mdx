## 概念

AstroBox 账号是我们全新推出的账号体系。它可以绑定 Github 账号、米坛账号、爱发电账号，以达成从「社区互动」到「付费资源激活」到「创作者资源绑定」的全体系账号服务。

## 账号注册与登录

在设置中点击 AstroBox 账户，点击上方的登录按钮，即可开始 AstroBox 的账号与注册。

![](/assets/images/docs/usage/account/3.png)

进入这个页面后，你可以直接凭借米坛账户登录，系统会一并为你注册好 AstroBox 账号并完成米坛账号与 AstroBox 账号的绑定。（不推荐在无账号注册的情况下直接使用 GitHub 和爱发电账号登录）

![](/assets/images/docs/usage/account/1.png)

你也可以点击注册按钮手动填写信息，通过邮箱来注册 AstroBox 账号。如果提示需要邀请码的，请尝试在 [https://ascas.waterflames.cn/login/astrobox](https://ascas.waterflames.cn/login/astrobox) 注册登录一下，再回到 AstroBox 重新唤起登录账号。如果提示「OUs2:"invalid_request"」相关字样，请给米坛设置一个头像再重新尝试～

![](/assets/images/docs/usage/account/2.png)

## 账号绑定

登录 AstroBox 账号后，需绑定其它平台账户的，请到 AstroBox 账号系統中添加，添加后，AstroBox 应用内不会实时显示绑定情况，但实际为已绑定，可使用的状态。如果想要更新显示状态，可以尝试重新登录一下 AstroBox 账号。

若你无法绑定米坛账号，提示「OUs2:"invalid_request"」相关字样，请给米坛设置一个头像再重新尝试～
