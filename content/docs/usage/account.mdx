## 概念

AstroBox 账号是我们全新推出的账号体系。它可以绑定 Github 账号、米坛账号、爱发电账号，以达成从「社区互动」到「付费资源激活」到「创作者资源绑定」的全体系账号服务。

## 账号注册与登录

在设置中点击 AstroBox 账户，点击上方的登录按钮，即可开始 AstroBox 的账号与注册。

![](/assets/images/docs/usage/account/3.png)

进入这个页面后，你可以直接凭借米坛账户登录，系统会一并为你注册好 AstroBox 账号并完成米坛账号与 AstroBox 账号的绑定。

![](/assets/images/docs/usage/account/1.png)

你也可以点击注册按钮手动填写信息，通过邮箱来注册 AstroBox 账号。

![](/assets/images/docs/usage/account/2.png)
