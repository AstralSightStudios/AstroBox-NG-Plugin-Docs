> AstroBox 账户管理由自部署的 Casdoor 驱动。

### 1. 前往注册页面

如果你已有[米坛社区账号](https://www.bandbbs.cn/)或 [Apple 账号](https://account.apple.com/)，可以快速注册 AstroBox 账号。前往[全球节点登录页面](https://cas.astralsight.space/login/astrobox)，点击下方的「使用 米坛社区 继续」或「Sign in with Apple」，按页面提示完成登录与注册。

也可以选择适合所在地区的节点，单独注册 AstroBox 账号。节点只需按访问位置区分：中国大陆用户优先选择中国大陆节点，其他地区用户优先选择全球节点。

### 2. 填写注册表单

| 字段 | 填写说明 |
| - | - |
| `Username` | 登录用户名，不能与已有账号重复，注册后不建议随意更改。 |
| `Display name` | 对外显示的名称，可以与其他用户重复。 |
| `Password` | 设置账号密码。请使用安全且能够记住的密码。 |
| `Confirm` | 再次输入相同的密码，用于确认密码填写无误。 |
| `Email` | 填写能够正常接收邮件的邮箱。可以使用 QQ 邮箱，格式为 `QQ号@qq.com`。 |
| `Email code` | 点击获取验证码后，填写邮箱收到的验证码。 |
| `Accept Terms of Use` | 勾选即表示同意 AstroBox 服务协议。注册前请阅读[相关协议](https://astrobox.online/agreements/)。 |
