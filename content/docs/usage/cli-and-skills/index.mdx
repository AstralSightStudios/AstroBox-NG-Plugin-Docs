AstroBox CLI (`astrobox-cli`) 是 AstroBox 的官方命令行工具。无需打开图形界面，你就可以在终端中完成设备管理、资源搜索、下载与安装等操作。CLI Skills 则是专为 AI Agent 设计的结构化能力封装，让 Agent 能够准确、安全地调用 CLI 完成 AstroBox 相关任务。
